# Scene Setup — Part 1

## تشغيل المشهد في خطوتين

**1.** في Unity Editor → شريط القوائم العلوي:
```
Simulation → Build Rope Scene
```

**2.** اضغط **Play** ▶

---

## التحكم أثناء التشغيل

| إدخال | وظيفة |
|---|---|
| **انقر على الحبل أو الدلو** | إمساك النقطة الأقرب |
| **سحب الفأرة (LMB مضغوط)** | تحريك المقبض يميناً / يساراً / أماماً / خلفاً |
| **عجلة التمرير** | رفع / خفض المقبض |
| **تحرير زر الفأرة** | إطلاق — الحبل يستعيد حركته الطبيعية |
| **F1** | إظهار / إخفاء نافذة المعاملات |

> المرساة العلوية (TopAnchor) ثابتة ولا تتحرك.

---

## نافذة المعاملات (Runtime — F1)

نافذة عائمة وقابلة للسحب تظهر أثناء التشغيل:

| قسم | معامل | تأثير |
|---|---|---|
| STIFFNESS | Stretch K | صلابة مقاومة التمدد (1.0 = صلب تماماً) |
| STIFFNESS | Bend/Twist K | مقاومة الانحناء والالتواء |
| STIFFNESS | Solver Iter | تكرارات الحل — أعلى = أدق وأقل تمدداً |
| PHYSICS | Bucket Mass | كتلة الدلو — يُحدَّث فورياً في المحاكاة |
| PHYSICS | Gravity Y | قوة الجاذبية الرأسية |
| GRAB | Pick Radius | مدى الإمساك بالبكسل |
| GRAB | Sensitivity | سرعة السحب بالفأرة |
